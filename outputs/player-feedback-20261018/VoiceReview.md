# 음성 볼륨 검토 (2026-10-18)

- 현재 설정 > 사운드의 음성 수신 음량과 전체 음량은 각각 0~100%입니다. 수신 AudioSource에는 두 값의 곱이 적용되어 100%를 넘기는 증폭은 없습니다.
- 기존 공간 음성은 3m 이내 최대 음량, 15m까지 거리 감쇠가 적용됩니다. 먼저 전체·음성 음량과 거리, Windows 마이크 입력 음량을 구분해 확인해야 합니다.
- 설치된 Photon Voice의 `WebRtcAudioDsp`에는 AGC(자동 이득), 잡음 억제, 에코 제거, 하이패스 기능이 있습니다. 현재 게임 프리팹에는 이 컴포넌트가 연결되지 않았습니다. OS/마이크 드라이버의 자체 보정 여부는 별개입니다.
- 개선 수단: 송신 Recorder에 AGC+잡음 억제를 연결하여 작은 음성 입력을 보정할 수 있습니다. 수신 쪽 추가 증폭은 별도의 AudioMixer 이득과 압축/리미터 등의 제어가 필요합니다. 이번 요청은 검토이므로 해당 기능을 추가하거나 기존 음성 처리를 바꾸지 않았습니다.
- 단순 선형 증폭은 목소리와 배경 잡음을 같은 비율로 키웁니다. 2배는 약 +6.02dB이며 잡음 RMS도 2배입니다. 합성 입력의 음성 peak 0.8에 2배 이득을 적용하면 full scale을 넘는 샘플이 생깁니다. 자세한 수치는 `voice-gain-review.json`에 있습니다.
- 실제 마이크·네트워크 음성과 사람의 청취로 잡음·찢어짐을 평가한 결과가 아닙니다. DSP 적용 시에는 조용한 말/큰 말/무음/스피커 사용 조건에서 별도 청취 검증이 필요합니다.

근거: `AudioSettingsComponent.cs`, `Voiceproximitycontroller.cs`, 설치된 `Assets/Photon/PhotonVoice/Code/WebRtcAudioDsp.cs` 및 합성 선형 증폭 계산.

라디오: 구현 가능합니다. 게임에 포함한 곡이나 허용된 오디오 파일을 재생하는 방식으로 구성할 수 있으며, 이번에는 제작하지 않았습니다.
